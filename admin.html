Connect to GitHub

Saving writes a line to data/corrections.csv (or data/hospitals.csv) in your repository. Paste a fine-grained GitHub token that can only edit this one repository: Settings → Developer settings → Fine-grained tokens → Repository access: gharpital only → Permissions: Contents: Read and write. The token is kept in this browser only.
